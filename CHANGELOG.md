# История изменений

Здесь фиксируются заметные изменения интерфейса, производительности и поведения.
Новые записи добавляются в раздел «Невыпущено» вместе с соответствующим патчем.
Датированные записи описывают выполненную работу; они не обозначают публикацию релиза.
Подробности реализации и проверок находятся в [журнале реализации](docs/ui-implementation.md).

## Невыпущено

### 2026-11-11 — подготовка сборки Ubuntu 24.04 x86_64

- Добавлены упаковка `.deb`, ярлык меню и иконка Linux; Qt и QML-модули включаются в пакет.
- Сохранение сессии на Linux использует Secret Service вместо отсутствующего платформенного хранилища.

### 2026-11-11 — исправление падения при запуске macOS

- Убран вызов установки иконки через Qt/Cocoa, вызывавший падение в `QImage::toCGImage` на macOS 27. Иконка Finder/Dock загружается штатно из ICNS в пакете приложения.
- Самопроверка сообщает используемый графический backend и отдельно проверяет PNG-ресурс и наличие ICNS.
- Добавлен скрипт упаковки релиза, который проверяет обычный запуск через Cocoa до упаковки и после распаковки ZIP. Одной offscreen-проверки для релиза теперь недостаточно.

### 2026-11-11 — иконка приложения и архив для GitHub

- Добавлена синяя иконка VK с мотивом диалога: PNG 1024×1024 и ICNS с комплектом размеров для Finder/Dock и Retina.
- Иконка встроена в Qt resources и macOS bundle; самопроверка приложения проверяет её загрузку.

- Подготовка релизного архива включает проверку подписи, самопроверку приложения и контрольную сумму SHA-256.

#### Интерфейс

- «Данные и память» оформлены карточками медиакэша, сохранённой истории и очереди отправки. Добавлены размер данных, заполнение лимита, пояснения и прокрутка для небольшого окна.

### 2026-11-10 — лёгкая панель профиля и список участников

- Аватары участников запрашиваются только рядом с видимой областью; при деактивации источник снимается, повторное отображение использует общий кэш.

#### Проверки

### 2026-11-10 — превью ссылок из API и LongPoll

#### Интерфейс

- Ссылки из `attachments[].link` показываются карточкой с картинкой, заголовком, описанием и доменом в обеих темах.
- Карточка открывает страницу по нажатию или Enter; у картинки есть состояния загрузки/ошибки и отдельный повтор.
- Превью появляется и из обычного ответа API, и после позднего раскрытия ссылки в уже показанном сообщении.

#### Обработка обновлений

- События 18/10018 адресно помечают сообщение для перечитывания: 10018 использует CMID, 18 сопоставляет глобальный ID с загруженной историей.
- Для private API передаются `updated_cmids`; в публичном режиме запрашивается нужный CMID, в том числе вне последней страницы истории.
- ID из `attachN_photo` не используется как URL: полные данные картинки берутся из обновлённого API-объекта `link.photo.sizes`.
- Устаревший ответ истории не заменяет более новое обновление. Повторы в одном пакете объединяются, строка сохраняет идентичность и не считается новым сообщением.
- Инвалидация сохранённого сообщения по CMID переживает перезапуск и изолирована по аккаунтам. Картинки загружаются по видимости и используют общий медиакэш.

#### Проверки

- Добавлены проверки начального API-ответа без LongPoll, обоих событий, повторов, устаревшего ответа истории и публичного API с сообщением вне последней страницы.
- Проверены ошибка картинки, повтор без открытия страницы, кэш, Enter, сохранение идентичности сообщения и отсутствие повторного уведомления.
- Превью визуально проверено в обеих темах на 780×560 с тестовым изображением.
- Все 12 наборов CTest прошли; пересобранный `VK.app` прошёл самопроверку и проверку ad-hoc подписи.

### 2026-11-10 — системные уведомления и передача файлов

#### Уведомления

- Добавлены уведомления macOS о новых входящих сообщениях и открытие нужного сообщения по нажатию на баннер.
- В «Настройки → Уведомления» доступны включение, звук, скрытие отправителя/текста и переход к системным разрешениям. Разрешение запрашивается при включении.
- Первичная история, повторы, исходящие, прочитанные и тихие сообщения не вызывают уведомления; учитываются отключённые уведомления бесед и активная открытая переписка.
- Уведомления одного диалога заменяют предыдущие; при смене аккаунта или отключении очищаются. Переход из уведомления проверяет аккаунт.
- Работают при запущенном приложении, включая фон и свёрнутое окно. APNs для полностью завершённого приложения не добавлен.

#### Передача файлов

- Отправка и скачивание получили отдельные карточки с именем файла, процентами, объёмом данных и очередью отправки.
- Ошибки, повтор и отмена двух направлений независимы. Ошибку можно скопировать отдельной кнопкой.
- Известный прогресс остаётся определённым на 0% и 100%; неизвестный размер показывает индикатор ожидания.
- События прогресса объединяются с интервалом 50 мс и не пересобирают/не сохраняют очередь вложений.
- HTTP-ошибка скачивания не сохраняется вместо файла и не перезаписывает прежний файл.

#### Проверки и ограничения

- Проверены отбор новых сообщений, отсутствие повторов, фокус, настройки приватности/звука, запрет разрешения, переход в переписку и настройки уведомлений.
- Проверены серии из 1000 событий прогресса, независимые направления передачи, HTTP-отказ без подмены файла и читаемость карточек на 780×560 в обеих темах.
- Настоящий системный баннер и разрешение на компьютере пользователя ещё требуют проверки после включения; автоматические проверки используют подставной backend.
- Все 12 наборов CTest прошли; обновлённое приложение прошло самопроверку и проверку ad-hoc подписи.

### 2026-11-09 — предыдущие доработки

#### Интерфейс

- Навигация по перепискам стрелками, Enter, Home/End и Escape с видимым фокусом.
- Профиль занимает отдельную колонку на широких окнах; поиск исключает несовпавших участников из списка.
- Компактная горизонтальная лента подготовленных вложений с удалением и управлением с клавиатуры.
- Тёмный просмотрщик фотографий с навигацией по альбому, масштабом, жестами и полным экраном.
- Видеоплеер для доступных VK потоков: пауза, перемотка, скорость, звук, повтор и полный экран; превью видео в ленте.

#### Производительность

- Поиск переписок объединяет быстрый ввод с задержкой 150 мс и учитывает IME.
- Сохранение позиции и определение прочтения используют созданные карточки вместо полного обхода истории.
- Модели объединяют соседние вставки, удаления и обновления; удаление начала истории не перемещает каждую оставшуюся строку.
- Медиа загружаются рядом с видимой областью; обновление прогресса передачи не пересоздаёт список вложений.
- Программный вывод видеокадров используется при software scene graph; аппаратный путь Qt сохранён.

#### Исправления

- IME-композиция не отправляется как сообщение до подтверждения ввода.
- Повтор после сетевой ошибки или повреждённого изображения доступен в просмотрщике и у стикеров.
- Передача файлов задаёт MIME-тип и сохраняет кириллицу в имени; временный отказ может повториться с новым upload URL.
- Ошибки передачи показывают хост и HTTP-код/сетевую причину без подписи URL; текст переносится в узком окне.
- Повтор неудачного скачивания использует прежний адрес назначения.

#### Проверки и ограничения

- На момент предыдущей записи прошли все 12 наборов CTest и самопроверка `build/VK.app`.
- Конкретная причина отказа на `pu.vk.ru` и успешная повторная загрузка с аккаунта пользователя пока не подтверждены живой проверкой.
- Полный паритет с web-клиентом, измерения FPS на Metal и все серверные права не подтверждены.
